## Old 3DS

- CIA on Old 3DS 11.17 / Luma 13.5: fails to start, no core.log or crash.txt (report, 0.9.1).
  The Luma dump showed the HOME Menu itself crashing: the CIA asked for the 96 MB memory mode,
  which leaves the HOME Menu too little memory. 0.9.2 uses the 80 MB mode retail games use, with
  less memory use to fit. Not yet confirmed on an Old 3DS.
- 0.9.2 with the 80 MB mode: some Old 3DS consoles still show a black screen at start (reports; open).
- 0.9.2 could stop at start with error D8E007FD when the recompiler checked which cores it may
  use (it asked about four cores; the Old 3DS has two); fixed in 0.9.3, not yet confirmed on an Old 3DS.
- ROMs are streamed from SD in 64 KB pages unless one fits with 12 MB of heap to spare.
